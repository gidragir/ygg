# ADR 0001: Начальная архитектура и топология ygg

- **Статус:** Принято
- **Дата:** 2026-11-08
- **Стек:** Generic / Multi-language

## Контекст
Инициализация кодовой базы `ygg`. Для обеспечения надежной автономной навигации ИИ-ассистентов зафиксирована трехуровневая модель контекста (OpenViking L0-L2).

## Архитектурные границы подсистем
- **Bin** (`bin`): Модуль и компоненты директории `bin` (1 файлов)
- **Docs** (`docs`): Модуль и компоненты директории `docs` (6 файлов)
- **Scripts** (`scripts`): Модуль и компоненты директории `scripts` (2 файлов)
- **Doctor** (`src_doctor`): Модуль и компоненты директории `src/doctor` (1 файлов)
- **Env** (`src_env`): Модуль и компоненты директории `src/env` (1 файлов)
- **Git** (`src_git`): Модуль и компоненты директории `src/git` (1 файлов)
- **Link** (`src_link`): Модуль и компоненты директории `src/link` (1 файлов)
- **Manifest** (`src_manifest`): Модуль и компоненты директории `src/manifest` (1 файлов)
- **Mod** (`src_mod`): Модуль и компоненты директории `src/mod` (1 файлов)
- **Pkg** (`src_pkg`): Модуль и компоненты директории `src/pkg` (1 файлов)
- **Sdk** (`src_sdk`): Модуль и компоненты директории `src/sdk` (1 файлов)
- **State** (`src_state`): Модуль и компоненты директории `src/state` (1 файлов)
- **Tests** (`tests`): Тесты проекта


## Решение
1. `L0_index.json` и `L0_index.md` служат единой точкой входа (Mental Map) с минимальным потреблением токенов.
2. Каждая подсистема изолирована в карточке L1 (`subsystems/*.md`) с перечислением точек входа и сигнатур.
3. Справочник команд L2 (`cli/commands.md`) фиксирует фактические команды сборки и верификации.

## Последствия
- Устраняется необходимость рекурсивного сканирования всего репозитория при каждом промпте.
- Агенты обращаются к точечным карточкам L1 по мере необходимости.
